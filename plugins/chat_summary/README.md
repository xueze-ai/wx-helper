# 当天聊天总结

- `/总结 昵称`：总结指定成员今天在当前群的有效文字发言。
- `/总结群聊`：总结当前群所有成员今天的有效文字发言。

称呼通过本群成员目录解析，默认微信名存在歧义时需本人 `/绑定` 一个不同称呼。未绑定者的发言也会进入全群总结，成员 ID 不会被作为模型中的身份编号。

功能使用 `llm_config.json` 中的模型配置，需要启用 `chat_summary` 插件以及成员配置中的 `history_enabled`、`daily_clear`。只记录启用后实际收到的文本，不查询微信旧历史。

清空、跨天或切换人格后，尚未发送的旧结果会取消。聊天文本会提交给自行配置的模型服务。
